## <span class="no">1</span> 지도 학습과 비지도 학습

머신러닝은 **정답(label)이 있느냐**에 따라 지도 학습(supervised learning)과 비지도 학습(unsupervised learning)으로 나눠요.

<figure><img src="/assets/img/ml/ml-map.png" alt="머신러닝 지도: 지도 학습은 분류(KNN, 로지스틱 회귀, 결정 트리, 랜덤 포레스트, SVM)와 회귀(선형 회귀), 비지도 학습은 군집화(K-means)와 차원 축소(PCA)" width="1590" height="871"></figure>

### 지도 학습: 정답이 있는 데이터로 학습

데이터마다 「사과」, 「귤」이나 「집값 3억」 같은 정답이 붙어 있어요. 맞히려는 값의 종류에 따라 둘로 나눠요.

**분류(classification)** : 정답이 범주예요. (사과인가 귤인가, 환자인가 정상인가)
- **KNN** : 가장 가까운 데이터 K개의 다수결
- **로지스틱 회귀** : 선형식을 시그모이드에 넣어 1일 확률을 계산
- **결정 트리** : 「가격 ≥ 4000인가?」 같은 조건으로 데이터를 계속 나누기
- **랜덤 포레스트** : 결정 트리 여러 개의 다수결
- **SVM** : 두 클래스 사이의 간격(margin)이 가장 큰 경계 찾기

**회귀(regression)** : 정답이 연속된 숫자예요. (집값, 내일 기온)
- **선형 회귀** : 오차 제곱의 합이 가장 작은 직선 찾기

이름에 「회귀」가 붙었지만 **로지스틱 회귀는 분류** 모델이에요. 출력이 확률이고, 그 확률로 0인지 1인지 나눠요.<br>
KNN과 결정 트리는 회귀에도 쓸 수 있어요.

### 비지도 학습: 정답 없이 패턴 찾기

- **군집화(clustering)** : 비슷한 데이터끼리 묶기. 대표가 **K-means**예요. 손님 구매 기록만 있을 때 비슷한 손님끼리 그룹으로 나누는 데 써요.
- **차원 축소(dimensionality reduction)** : 특성(feature)이 너무 많을 때 정보를 최대한 남기며 개수를 줄이기. 대표가 **PCA**예요.

### KNN과 K-means는 이름만 비슷해요

| | KNN | K-means |
|---|---|---|
| 갈래 | 지도 학습 (분류) | 비지도 학습 (군집화) |
| 하는 일 | 새 데이터의 클래스 맞히기 | 비슷한 데이터끼리 묶기 |
| K의 뜻 | 볼 이웃 수 | 만들 클러스터 수 |

딥러닝은 이 갈래와 따로 있는 게 아니라 **모델 종류**예요. 신경망을 여러 층 쌓은 모델이고, 지도 학습에도 비지도 학습에도 써요.

## <span class="no">2</span> 거리 재는 세 가지 방법

KNN처럼 「가까운 데이터」를 찾는 모델은 두 점 사이의 거리를 먼저 계산해요. 두 점 $$x = (x_1, \dots, x_n)$$, $$y = (y_1, \dots, y_n)$$에 대해 이렇게 정의해요.

**유클리디안 거리(Euclidean distance)** : 직선 거리

$$d_E(x, y) = \sqrt{\sum_{i=1}^{n} (x_i - y_i)^2}$$

**맨해튼 거리(Manhattan distance)** : 축 방향 차이의 합

$$d_M(x, y) = \sum_{i=1}^{n} \lvert x_i - y_i \rvert$$

**체비셰프 거리(Chebyshev distance)** : 축 방향 차이 중 가장 큰 값

$$d_C(x, y) = \max_{i} \lvert x_i - y_i \rvert$$

**A(0, 0)에서 B(3, 4)까지** 로 계산해 볼게요. 좌표끼리 뺀 차이는 $$\lvert 3-0 \rvert = 3$$, $$\lvert 4-0 \rvert = 4$$예요.

<figure><img src="/assets/img/ml/distance-three.png" alt="A(0,0)에서 B(3,4)까지 맨해튼 거리 7, 유클리디안 거리 5, 체비셰프 거리 4의 경로" width="856" height="1016"></figure>

| 방법 | 계산 | 거리 |
|---|---|---|
| 맨해튼 | 3 + 4 | 7 |
| 유클리디안 | √(3² + 4²) | 5 |
| 체비셰프 | max(3, 4) | 4 |

### 체비셰프 거리가 max인 이유

체비셰프 거리는 **대각선 이동도 한 번으로 셀 때 필요한 최소 이동 횟수**와 같아요.<br>
(0, 0)에서 대각선으로 3번 가면 (3, 3)이에요. x 차이는 다 줄었고 y 차이 1이 남아서 위로 한 번 더 가요. 모두 4번이에요.<br>
대각선 이동은 두 축의 차이를 동시에 하나씩 줄이니, 결국 **더 큰 차이만큼** 움직이게 돼요.

### 민코프스키 거리는 셋을 하나로 묶은 식

$$d_p(x, y) = \Big( \sum_{i=1}^{n} \lvert x_i - y_i \rvert^p \Big)^{1/p}$$

- $$p = 1$$ → 맨해튼 거리
- $$p = 2$$ → 유클리디안 거리
- $$p \to \infty$$ → 체비셰프 거리

## <span class="no">3</span> 정규화와 표준화 차이

둘 다 특성(feature)마다 다른 값의 크기를 맞추는 방법이에요. **기준점(0)을 어디에 두느냐**가 달라요.

**정규화(Min-Max normalization)** : 최솟값을 0, 최댓값을 1로

$$x' = \frac{x - x_{min}}{x_{max} - x_{min}}$$

**표준화(standardization)** : 평균을 0, 표준편차를 1로

$$z = \frac{x - \mu}{\sigma}$$

$$\sigma = \sqrt{\frac{1}{N}\sum_{i=1}^{N}(x_i - \mu)^2}$$

**점수 50, 70, 90** 이면 $$\mu = 70$$, $$\sigma = 16.33$$이에요.

<figure><img src="/assets/img/ml/scaling.png" alt="점수 50, 70, 90이 정규화하면 0, 0.5, 1이 되고 표준화하면 −1.22, 0, +1.22가 되는 수직선" width="1567" height="688"></figure>

| 점수 | 정규화 | 표준화 |
|---|---|---|
| 50 | (50 − 50) / 40 = 0 | (50 − 70) / 16.33 = −1.22 |
| 70 | 0.5 | 0 |
| 90 | 1 | +1.22 |

위 $$\sigma$$는 $$N$$으로 나누는 모집단 표준편차예요. scikit-learn의 StandardScaler가 이 방식이에요. pandas의 `.std()`는 기본으로 $$N-1$$로 나누는 표본 표준편차라서 ±1이 나와요.

정규화의 0.5는 최솟값과 최댓값의 **가운데 위치**예요. 평균이 꼭 0.5인 건 아니에요. 점수가 50, 60, 90이면 정규화 값은 0, 0.25, 1이고 평균은 0.42예요.<br>
표준화는 어떤 데이터든 변환 뒤 평균이 **항상 0**, 표준편차가 1이에요.

### 왜 크기를 맞출까?

거리를 계산할 때 연봉(수천만)과 나이(수십)를 그대로 쓰면, 값이 큰 연봉의 차이가 거리를 거의 다 결정해요.<br>
크기를 맞춰야 두 특성이 비슷한 비중으로 반영돼요.

### 무엇을 고를까?

정규화는 최솟값과 최댓값 **두 값에 전부 달려 있어서 이상치(outlier)에 약해요.**<br>
점수 50, 60, 70, 80 사이에 1000이 하나 끼면, 나머지 네 개가 0에서 0.03 사이로 몰려요.

- **범위가 정해진 데이터** (이미지 픽셀 0에서 255, 설문 1점에서 5점) → 정규화
- **범위가 정해지지 않았거나 이상치가 있는 데이터** (가격, 연봉) → 표준화

실습에서는 둘 다 해 보고 성능이 좋은 쪽을 고르는 경우도 많아요.

## <span class="no">4</span> KNN은 이웃 K개의 다수결

KNN(K-nearest neighbors)은 **정답이 있는 데이터 중 새 데이터와 가장 가까운 K개를 찾아, 그 K개의 정답 중 가장 많은 클래스를 예측값으로** 써요.

$$\hat{y} = \underset{c}{\arg\max} \ \sum_{i \in N_K(x)} \mathbf{1}(y_i = c)$$

$$N_K(x)$$는 새 데이터 $$x$$에서 가장 가까운 K개, $$\mathbf{1}(y_i = c)$$는 정답이 클래스 $$c$$면 1, 아니면 0이에요. 클래스마다 개수를 세서 가장 많은 쪽을 고른다는 뜻이에요.

<figure><img src="/assets/img/ml/knn-k5.png" alt="K=5일 때 새 점에서 가장 가까운 5개 중 사과 2개, 귤 3개라서 새 점을 귤로 예측하는 KNN 그림" width="1007" height="968"></figure>

새 점(★)에서 가장 가까운 5개는 사과 2개, 귤 3개라서 **귤**로 예측해요.

### K는 데이터 묶음 크기가 아니라 이웃 수

K를 테스트 데이터 묶음 크기로 착각하기 쉬워요.

- **테스트 데이터** : 최종 채점용으로 따로 떼어 둔 데이터 (예: 20개)
- **K** : 데이터 **하나**를 예측할 때 참고하는 이웃 수 (예: 5개)

테스트 데이터가 20개면, 20개 **각각이** 이웃 5개를 봐요.

### K는 몇으로 할까?

**√n으로 시작** : 학습 데이터 개수 $$n$$의 제곱근을 출발값으로 많이 써요. 100개면 √100 = 10이고, 두 클래스일 때 동점(5대 5)을 피하려고 홀수인 **9나 11**로 해요.

**Elbow Method로 고르기** : K를 바꿔 가며 오차율을 재고, 오차율이 가장 낮거나 더 이상 줄지 않는 K를 골라요.

1. K 후보를 정해요 (1, 3, 5, 7, …).
2. K마다 검증 데이터(validation data)로 오차율을 재요. 테스트 데이터는 마지막 채점에만 써요.
3. K를 가로축, 오차율을 세로축으로 그래프를 그려요.
4. 오차율이 가장 낮거나 꺾이는 지점의 K를 골라요.

**실험** : 두 클래스가 겹쳐 있는 2차원 데이터 300개(클래스마다 150개, 정규분포 중심 (2, 2)와 (2.9, 2.9), 표준편차 0.9) 중 200개를 학습 데이터, 100개를 검증 데이터로 썼어요.

<figure><img src="/assets/img/ml/knn-elbow.png" alt="K를 1부터 31까지 바꿨을 때 검증 오차율이 K=1에서 24%, K=5에서 20%로 가장 낮고 그 뒤로는 21%와 23% 사이에서 오르내리는 그래프" width="1303" height="691"></figure>

K = 1일 때 24%에서 K = 5일 때 20%로 가장 낮아지고, 그 뒤로는 21%와 23% 사이에서 오르내려요. 이 데이터에서는 K = 5를 골라요.<br>
K가 너무 작으면 가까운 데이터 몇 개의 노이즈에 흔들리고, 너무 크면 멀리 있는 다른 클래스 데이터까지 투표에 들어와요.

Elbow Method를 설명할 때 「K=2면 클러스터 2개, K=3이면 클러스터 3개」 같은 **K-means** 그림을 같이 쓰는 경우가 있어요. 그 K는 클러스터 수라서 KNN의 K와 뜻이 달라요.

### KNN은 파라미터를 학습하지 않아요

KNN은 학습 단계에서 데이터를 저장만 하고, 예측할 때 거리를 계산해요. 그래서 **lazy learning(게으른 학습)** 이라고 불러요.<br>
손실을 줄이도록 파라미터를 업데이트하는 학습은 아래 로지스틱 회귀의 **경사하강법**부터 나와요.

## <span class="no">5</span> 분류 모델 평가 지표 정리

분류 모델은 **혼동행렬(confusion matrix)** 의 네 칸으로 평가 지표를 계산해요.

- **TP** (true positive) : 실제 양성을 양성으로 예측
- **FN** (false negative) : 실제 양성을 음성으로 예측
- **FP** (false positive) : 실제 음성을 양성으로 예측
- **TN** (true negative) : 실제 음성을 음성으로 예측

**예: 100명 검사, 실제 환자 10명.** 모델이 15명을 환자(양성)로 예측했고, 그중 8명이 실제 환자예요.

<figure><img src="/assets/img/ml/confusion-matrix.png" alt="혼동행렬 TP 8, FN 2, FP 7, TN 83과 Precision 8/15, Recall 8/10" width="908" height="741"></figure>

$$\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}$$

= (8 + 83) / 100 = **0.91**

$$\text{Precision} = \frac{TP}{TP + FP}$$

= 8 / 15 = **0.53**

$$\text{Recall} = \frac{TP}{TP + FN}$$

= 8 / 10 = **0.80**

$$\text{F1} = \frac{2 \cdot P \cdot R}{P + R}$$

= 2 × 0.53 × 0.80 / (0.53 + 0.80) = **0.64** ($$P$$는 Precision, $$R$$은 Recall)

- **Precision** : 양성으로 예측한 것 중 실제 양성의 비율
- **Recall** : 실제 양성 중 찾아낸 비율
- **F1** : Precision과 Recall의 조화 평균(harmonic mean)

Accuracy 0.91은 높아 보이지만, 정상이 90명이라 모두 정상으로 예측해도 0.90이에요. 클래스 비율이 한쪽으로 치우친 데이터에서는 Precision, Recall, F1을 같이 봐요.

### F1은 왜 조화 평균일까?

조화 평균은 **두 값 중 작은 쪽에 가깝게** 나와요. 그래서 둘 중 하나만 높은 모델을 걸러 내요.<br>
Precision 1.0, Recall 0.01인 모델로 비교하면 이래요.

- 산술 평균 : (1.0 + 0.01) / 2 = **0.505**
- F1 : 2 × 1.0 × 0.01 / (1.0 + 0.01) = **0.02**

산술 평균으로는 괜찮아 보이지만, F1은 Recall이 낮다는 걸 그대로 보여 줘요.

### heatmap의 annot=True

혼동행렬을 seaborn `heatmap`으로 그릴 때 `annot=True`를 넣으면 **각 칸에 값을 표시**해요. 빼면 색만 나와요.

## <span class="no">6</span> 로지스틱 회귀와 손실함수

로지스틱 회귀는 선형식 $$z = wx + b$$를 **시그모이드 함수**에 넣어 1일 확률 $$p$$를 계산해요.

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

$$p = \sigma(wx + b)$$

$$\sigma(z)$$는 어떤 $$z$$든 0과 1 사이 값으로 바꾸고, $$z = 0$$일 때 0.5예요. 보통 $$p \ge 0.5$$면 1, 아니면 0으로 분류해요.

### OLS 직선을 그대로 쓰면 안 되는 이유

**실험** : $$x = 1, 2, \dots, 8$$에 정답 $$y = 0, 0, 0, 1, 0, 1, 1, 1$$인 데이터예요.

<figure><img src="/assets/img/ml/sigmoid-ols-vs-logistic.png" alt="OLS 직선 z=0.17x−0.25를 시그모이드에 넣으면 확률이 0.48에서 0.75로 밋밋하고, log loss로 찾은 z=1.28x−5.77을 넣으면 0.011에서 0.989로 확실히 갈라지는 그림" width="1868" height="767"></figure>

- **선형 회귀(OLS)로 찾은 직선** $$z = 0.17x - 0.25$$ : 모든 점과의 오차 제곱을 줄이려고 기울기가 완만해요. 시그모이드에 넣으면 $$x = 1$$에서 0.48, $$x = 8$$에서 0.75로 0과 1이 잘 갈라지지 않아요.
- **log loss로 찾은 직선** $$z = 1.28x - 5.77$$ : 기울기가 가팔라서 $$x = 1$$에서 0.011, $$x = 8$$에서 0.989예요. $$p = 0.5$$가 되는 경계는 $$x = 4.5$$예요.

그래서 로지스틱 회귀의 $$w, b$$는 OLS가 아니라 아래 손실함수로 찾아요.

### 손실함수 log loss (BCE)

$$L(w, b) = \frac{1}{N} \sum_{i=1}^{N} \ell_i$$

$$\ell_i = -\big[\, y_i \log p_i + (1 - y_i) \log (1 - p_i) \,\big]$$

딥러닝에서는 같은 식을 **BCE(binary cross-entropy)** 라고 불러요.

- 정답 1인데 $$p = 0.9$$ → $$-\log 0.9 = 0.11$$ (작은 손실)
- 정답 1인데 $$p = 0.1$$ → $$-\log 0.1 = 2.30$$ (큰 손실)

확신하고 틀릴수록 손실이 크게 늘어나요.

### 경사하강법으로 w, b를 찾는 이유

선형 회귀는 손실을 미분해서 0으로 놓고 풀면 $$w, b$$가 식 하나로 바로 나와요(정규방정식).<br>
로지스틱 회귀는 시그모이드 때문에 미분을 0으로 놓은 식을 $$w = \cdots$$ 꼴로 풀 수 없어요. 그래서 기울기를 계산해 조금씩 업데이트하는 **경사하강법**을 써요. 기울기는 이렇게 간단하게 나와요.

$$\frac{\partial L}{\partial w} = \frac{1}{N} \sum_{i=1}^{N} (p_i - y_i)\, x_i, \qquad \frac{\partial L}{\partial b} = \frac{1}{N} \sum_{i=1}^{N} (p_i - y_i)$$

위 실험의 $$z = 1.28x - 5.77$$도 (w, b) = (0, 0)에서 출발해 이 기울기로 경사하강법(learning rate 0.05)을 200,000번 반복해 찾은 값이에요.<br>
scikit-learn의 `LogisticRegression().fit(X, y)`는 경사하강법을 개량한 최적화 방법을 쓰고, 기본으로 L2 규제도 조금 들어가요.

### 로지스틱 회귀 = 은닉층 없는 퍼셉트론

로지스틱 회귀는 **층이 하나뿐인 가장 작은 신경망**과 같은 구조예요.

- 원래 퍼셉트론 : 계단 함수라 0 아니면 1만 나와요. 기울기가 거의 모든 곳에서 0이라 경사하강법으로 학습할 수 없어요.
- 로지스틱 회귀 : 시그모이드라 미분이 되고 확률이 나와요. 경사하강법으로 학습해요.

여기에 층을 여러 개 쌓으면 딥러닝 모델이 돼요.

## <span class="no">7</span> 다중공선성이란

다중공선성(multicollinearity)은 **입력 특성끼리 강하게 상관된 상태**예요.

집값을 예측하는데 면적(㎡) $$x_1$$과 면적(평) $$x_2$$를 같이 넣었다고 해 봐요. 1평은 약 3.3058㎡라서 $$x_2 = x_1 / 3.3058$$이에요.

$$\hat{y} = w_1 x_1 + w_2 x_2 = \Big( w_1 + \frac{w_2}{3.3058} \Big) x_1$$

예측값은 $$w_1 + w_2/3.3058$$ 한 값으로만 정해져요. 그래서 $$(w_1, w_2) = (100, 0)$$과 $$(500, -1322.3)$$은 예측이 같아요.

- 같은 예측을 내는 $$w$$ 조합이 무수히 많아서, 학습 결과 $$w$$가 엉뚱하게 크거나 부호가 반대로 나올 수 있어요.
- 데이터가 조금만 바뀌어도 $$w$$가 크게 흔들려요.

선형·로지스틱 회귀는 $$w$$로 「이 특성이 결과에 얼마나 영향을 주나」를 해석하는 모델이라 다중공선성을 특히 조심해야 해요.<br>
상관이 강한 특성 중 하나를 빼는 게 가장 간단한 해결책이고, 규제(L2)나 PCA를 쓰기도 해요.
