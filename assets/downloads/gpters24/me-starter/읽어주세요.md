압축을 푼 me 안의 파일을 이미 사용 중인 me의 해당 자리에 넣습니다.
me 안에 me를 하나 더 만드는 방식이 아닙니다.
같은 이름의 기존 파일이 있다면 덮어쓰지 말고 AI에게 내용을 비교해서 필요한 줄만 합쳐 달라고 요청하세요.
보관함의 실제 이름이 Obsidian Vault와 다르면 AGENTS.md의 경로도 맞춰 주세요.

Obsidian은 기존 보관함을 계속 사용합니다. 설정 폴더나 새 보관함을 추가하는 세트가 아닙니다.
Codex 또는 Claude Code에서 me를 작업 위치로 열고 새 작업을 시작합니다.
AI에게 현재 작업 위치와 실제로 읽은 규칙 파일을 확인해 달라고 요청합니다.
일반 채팅의 파일 첨부만으로 내 컴퓨터에 파일이 저장되거나 수정되지는 않습니다.
