# AI 작업 폴더 시작 안내

이 파일은 **사용자가 만든 AI 작업 폴더 바로 안**에 둡니다. 폴더 이름은 `me`일 필요가 없습니다.

## 먼저 확인할 것

1. 현재 작업 폴더와 그 안의 **Obsidian 보관함 하나**를 실제로 확인합니다. 이름을 짐작하지 않습니다.
2. 보관함의 `AI협업규칙.md`를 읽고 작업합니다. 파일이나 폴더에 접근할 수 없으면 그 사실을 알려 줍니다.
3. 프로젝트 원본 폴더와 보관함은 AI 작업 폴더 안에 **나란히** 둡니다. 이미 다른 곳에 있는 원본도 제자리에 둡니다.

“목차에 넣어 줘”라는 요청은 원본을 옮기는 일이 아닙니다. AI가 보관함 안에 프로젝트 **소개 노트**를 만들고 기존 **홈/목차**에서 연결합니다. 원본의 위치를 소개 노트에 적습니다. 다운로드만으로 목차가 자동으로 생긴다고 설명하지 않습니다.

현재 작업 폴더가 이 파일이 있는 폴더와 다르면, 사용자가 지정한 AI 작업 폴더와 보관함을 먼저 확인합니다. 일반 웹 채팅에서 첨부만 읽은 경우에는 컴퓨터 파일을 수정했다고 말하지 않습니다.

기존 규칙에 수업 자료를 합칠 때는 현재 파일들을 먼저 읽습니다. 바꿀 내용을 짧게 제안하고 사용자가 확인한 뒤 필요한 부분만 수정합니다. 기존 프로젝트 원본과 기록은 유지합니다.
