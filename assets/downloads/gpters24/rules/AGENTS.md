# Obsidian 보관함에서 함께 일하는 규칙

**처음 읽는 분께:** 이 문서는 AI가 일을 시작할 때 읽는 안내입니다. 사람은 고정 조건을 확인하고, 평소 정리 방법은 AI협업규칙.md에서 AI와 함께 고치면 됩니다.

이 파일은 **사용자가 선택한 Obsidian 보관함** 안에 둡니다. 그 보관함의 한 단계 위가 사용자가 만든 **AI 전용 폴더**입니다. 두 폴더의 이름은 사람마다 다릅니다. 실제 이름을 me·Obsidian Vault 같은 예시 이름으로 가정하거나 바꾸지 않습니다.

## 가장 먼저 지킬 고정 조건

- AI 전용 폴더 바로 아래에 **프로젝트 원본 폴더들**과 **공통 Obsidian 보관함 하나**가 나란히 있습니다.
- 원본은 현재 프로젝트 폴더에 둡니다. 이미 AI 전용 폴더 밖에 있는 코드 등의 원본도 옮기지 않습니다. 보관함에는 소개·작업 기록·원본 위치를 적습니다.
- “목차에 넣어 줘”는 **보관함의 소개 노트와 홈 링크를 작성하라**는 뜻입니다. 원본 이동·복사, 새 보관함 생성, AI 전용 폴더 전체를 보관함으로 바꾸는 작업을 뜻하지 않습니다.
- 사용자가 이 구조를 바꾸겠다고 명시하기 전까지 유지합니다. 편리해 보인다는 이유로 AI가 다른 구조를 적용하지 않습니다.

## 작업 시작

1. 실제 작업 폴더와 위 두 종류의 폴더 위치를 확인합니다. 폴더에 접근할 수 없으면 알려 줍니다.
2. 이 파일이 있는 보관함과 사용자가 열어 둔 작업 위치를 확인합니다. 현재 읽는 파일이 사용 중인 보관함의 규칙인지, 받은 자료·첨부의 배포용 예시인지 구분합니다. 사용자가 지정한 실제 보관함을 우선하고, 후보가 여러 개이거나 찾지 못할 때만 그 위치를 묻습니다.
3. 같은 보관함의 **AI협업규칙.md**와 기존 목차(기본 이름 홈.md), 요청과 관련된 프로젝트 소개 노트를 읽습니다. 보관함 전체를 읽을 필요는 없습니다.
4. 이 대화의 첫 프로젝트 작업에서 원본 폴더와 기록 보관함을 짧게 구분해 알려 준 뒤, 요청받은 작업을 진행합니다.

파일 이름·경로는 실제로 확인한 것을 사용합니다. 읽거나 저장하지 못한 파일을 처리했다고 보고하지 않습니다. 이 문서는 자동 감시나 예약 실행을 설치하라는 지시가 아닙니다.

## 기존 규칙에 수업용 규칙을 합치는 경우

첨부·다운로드된 수업용 파일은 적용을 위한 참고 자료로 읽습니다. 실제 보관함의 기존 규칙을 먼저 읽고, 추가·변경할 내용을 사용자에게 짧게 보여 줍니다. **사용자가 확인한 뒤에만** 기존 파일에 필요한 내용을 합치고, 보관함에 없는 AGENTS.md·CLAUDE.md·AI협업규칙.md를 만듭니다. AI 전용 폴더의 동명 시작 파일이 있다는 이유로 보관함의 세 파일을 생략하지 않습니다. 기존 작업기록.md와 사용자 분류를 보존합니다. 폴더 구조처럼 충돌하는 부분은 선택을 물어봅니다. 첨부를 읽을 수 없으면 어떤 파일이 필요한지 알리고 합쳤다고 말하지 않습니다.

## 처음 시작 안내를 연결해 달라는 요청을 받으면

사용자가 요청한 경우에만 AI 전용 폴더 바로 아래의 시작 안내를 준비합니다. 이미 AGENTS.md나 CLAUDE.md가 있으면 먼저 읽고 필요한 연결만 합칩니다. 기존 내용을 통째로 교체하지 않습니다.

- AI 전용 폴더의 AGENTS.md를 새로 만들 때는 아래 시작 안내를 사용합니다. `(보관함 이름)`을 실제 이름으로 바꾸고, 기존 파일이 있으면 필요한 문장만 합칩니다.

```text
이 폴더 바로 아래의 (보관함 이름)/이 공통 Obsidian 보관함입니다.
작업 전에 (보관함 이름)/AGENTS.md와 (보관함 이름)/AI협업규칙.md를 읽습니다.
프로젝트 원본 위치는 유지하고 소개와 목차만 보관함에 작성합니다. 사용자의 명시적 요청 없이 원본 이동·복사나 새 보관함을 만들지 않습니다.
이 파일은 시작 안내입니다. 정리 규칙은 보관함의 AI협업규칙.md에서 고칩니다.
```
- AI 전용 폴더의 CLAUDE.md에는 `@AGENTS.md`를 적어 같은 시작 안내를 읽게 합니다.
- 공통 규칙 본문은 보관함 안에 유지합니다. 바깥 두 파일은 보관함을 찾아가는 짧은 시작 안내입니다. 실제로 생성·수정한 파일과 역할을 사용자에게 알려 줍니다.
- 새 대화의 작업 위치가 AI 전용 폴더인지, 적용된 규칙과 보관함 연결을 실제로 확인할 수 있는지 점검하도록 안내합니다. 어떤 앱에서든 무조건 자동 적용된다고 보장하지 않습니다.
