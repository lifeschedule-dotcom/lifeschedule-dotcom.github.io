# AI협업규칙

사람과 AI가 함께 지키는 정리 약속입니다.

## 폴더 구조

```text
me/                              ← AI 작업 폴더
├─ AGENTS.md · CLAUDE.md
├─ 프로젝트 이름/                 ← 원본 (파일·사진·코드)
└─ Obsidian Vault/               ← 기록
   ├─ 홈.md                      ← 목차
   ├─ AI협업규칙.md               ← 이 파일
   └─ 프로젝트/
      └─ 프로젝트 이름/
         ├─ 프로젝트 이름.md      ← 첫 장
         └─ 상세기록/
```

## 첫 장

프로젝트마다 첫 장을 하나 만들고, `홈.md`에 링크합니다.
첫 장은 네 칸입니다.

- 프로젝트 내용요약 : 무엇을 왜 하는지, 지금 상태
- 개발기록 : 날짜와 만든 것, 한 줄씩
- 오류보완기록 : 날짜와 고친 문제, 한 줄씩
- 자료위치 : 원본 폴더 위치

모르는 내용은 지어내지 말고 물어봅니다.

## 작업 기록

- 시작할 때 : 첫 장과 최근 상세기록을 읽습니다.
- 끝났을 때 : 말하지 않아도 기록하고, 어느 파일에 적었는지 알려 줍니다.
  1. `상세기록`에 새 파일 `작업 내용 - 날짜.md` (한 일, 못 한 일)
     다음 할 일은 사용자와 정했을 때만 적습니다.
  2. 첫 장의 개발기록이나 오류보완기록에 한 줄
- "md 파일 업데이트해줘"라고 하면 위 기록을 합니다. 새 프로젝트면 `홈.md`에도 링크합니다.

## 문서 정리

- 기획서·안내 문서도 `상세기록`에 넣고, 첫 장에서 링크합니다.
- 큰 세부 작업은 하위 폴더를 만들고 첫 장을 따로 둡니다.
