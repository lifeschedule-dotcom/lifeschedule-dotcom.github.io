파티룸안내부터 문의 답장·환급 요청까지, 예약 손님 응대를 대신 하는 어플

문제
네이버 예약이 들어올 때마다 저장해 둔 문서를 열어 잔금·보증금·주차 안내를 복사해 붙이고, 추가 인원에 따라 추가 금액을 계산하고, 은행 앱을 열어 입금됐는지 확인하고, 포토리뷰 답장이 없는 손님에게는 다시 연락했습니다.
예약은 불시에 들어오니 바로 응대하려면 핸드폰을 계속 주시해야 했습니다.
이용 전후에도 주차·쓰레기·식기 같은 문의에 답하고, 연장·인원 추가는 입금까지 확인해야 했습니다.
결과
앱이 예약 정보를 읽어 안내·리뷰 이벤트 문자를 보내고, 보증금이 들어오면 확인해 예약 확정 등 일련의 문자를 일정에 맞춰 발송. 주차·추가 금액·쓰레기·식기·미성년 동의서 문의에는 앱이 바로 답장. 연장·인원 추가·주차 요청은 입금까지 맞으면 앱이 확인 답장. 인원이 줄면 환급액에도 반영. 네이버 예약이 확정되면 스페이스클라우드의 같은 시간을 자동으로 막음. 청소 일정과 수건·생수 개수는 선생님 전용 화면으로 전달. 직접 하는 일은 개인 문의 답장, 발송 확인, 환급 송금뿐 — 예약 때문에 핸드폰을 계속 볼 필요가 없어짐.

2026년 10월 25일 운영판 기준. 건물 주차 요청은 실제 손님 건에서 입금 확인과 자동 답장까지 확인했습니다. 연장·인원 추가는 실제 손님 건 확인 전입니다.

코인노래방무인 시간에도 손님이 직접 남은 곡을 꺼내 쓰는 키핑 시스템

문제
정액권 손님은 남은 곡을 키핑해 뒀다가 다음에 쓸 수 있습니다.
그런데 무인 시간대에 그 곡을 쓰려면 손님이 카운터 전화번호로 전화하고, 사장이 받아서 매장 프로그램에 손으로 넣어줘야 했습니다.
전화를 놓치면 손님은 기다리고, 사장은 무인 시간 내내 전화에 신경을 써야 했습니다
결과
손님이 직접 원하는 방에 원하는 곡 수만큼 키핑된 곡을 사용전화 요청이 없어지고, 손님은 기다릴 필요가 없어짐

코인노래방 · 에어비앤비 · 파티룸알바 출석 기록 + 인건비 자동 계산 시스템

문제
10명이 넘는 알바생의 출퇴근을 카톡과 종이 출석부로 더블 체크하고, 정산일에 그걸 엑셀에 옮겨 적어 시급·주휴수당·세금을 계산했습니다.
엑셀 함수를 만들어 놨지만, 시급이 다른 친구가 대타를 하거나 예외적인 주휴수당을 계산하는 일이 매번 까다로웠습니다
결과
직접 작성 및 확인 2시간 → 숫자 확인 10분

코인노래방마이크 소리가 그대로 들어가는 노래방 셀프 촬영

문제
부가 수익을 낼 방법을 고민하다가, 손님이 노래 부르는 모습을 셀프로 찍고 싶어 하는 니즈를 발견했습니다.
그런데 폰으로 찍으면 소리가 웅웅거리고 조명도 각도도 안 나옵니다.
두 니즈를 한 번에 잡으려면, 방 안에서 조명까지 갖춘 채로 손님이 직접 결제하고 촬영하는 시스템이 필요했습니다
결과
손님이 방 안에서 QR로 결제하고 촬영 버튼을 누르면 조명이 켜지고, 마이크로 들어가는 노래 소리가 그대로 영상에 담김끝나면 손님 폰에서 바로 확인·저장베타테스트 후 사업으로는 중단

콘텐츠매일 아침 7시, 손 안 대고 발행되는 해외 뉴스 블로그

문제
한국 신문만 보는 것보다 해외 신문의 관점도 같이 보면 좋겠다고 생각하던 중에, 워드프레스로 광고 수익을 내는 것에 도전해 봤습니다.
다만 자료를 모으고 글을 쓰는 시간은 거의 0에 가깝게 줄이고 싶었습니다
결과
매일 아침 7시에 경제·언론·기술 3개 주제가 하루 하나씩 번갈아 발행되고, 영어·한국어 2개 언어로 워드프레스 두 곳에 이미지까지 붙어 자동으로 올라갔습니다. 발행에 드는 시간 0분다만 이 구조에서는 글보다 사람이 검색하는 키워드·알고리즘·유입이 더 중요하다는 걸 확인하고, 여기에 시간을 쏟지 않기로 결정해 운영을 종료했습니다
